# UI 规范（移动端 & 浮层）

这个站是 Tailwind + 自建组件，踩过的坑都写在这。

## 一、浮层层级（z-index）——必须遵守

站点已有的固定条层级是写死的，自建浮层低于它们就会被压住（v1.6.1 面板就栽在这）：

| 层 | 层级 | 组件 |
|---|---|---|
| 顶部导航 | `z-[999]` | `MobileHeader` |
| 底部 tab | `z-[600]` | `MobileBottomNav` |
| **自建模态/抽屉** | **`z-[1000]` 起** | 弹窗、面板、选择器 |
| 轻量下拉（在弹层内部） | `z-50` | 只用于父级已建立层叠上下文的情况 |

规则：
1. 新的全屏浮层一律 `fixed inset-0 z-[1000]`，不要用 50/100；
2. 浮层内部的下拉/菜单用 `z-50` 相对父级即可，但父级必须自己形成 stacking context（`relative` + z）；
3. 浮层遮罩点击关闭要保留，`onClick` 放在遮罩层而不是内容层。

## 二、移动端抽屉形态

- 手机（`<640px`）：`items-end` + 上圆角 `rounded-t-2xl` + 抓手条 + `max-h-[62vh]`（别超过 70vh，否则观感就是“整屏”）；
- 桌面（`sm:`）：居中卡片 `sm:max-w-lg` + `sm:rounded-xl`；
- 底部固定按钮区必须加 `pb-[calc(0.75rem+env(safe-area-inset-bottom))]`；
- 内容区 `overflow-y-auto overscroll-contain`，头部/底部 `flex-shrink-0`。

## 三、验收清单（UI 改动必做）

1. **按 375 / 390 / 430px 宽度看**，不能只看桌面宽度（手机 424px 时 `max-w-lg` 等于没有）；
2. 顶栏/底栏不能被遮住或遮住别人（对照上面层级表）；
3. 浮层关闭按钮可点、遮罩可点；
4. 底部主按钮不被 tab 栏挡，不被安全区切；
5. 改完必须**真机或窄视口截图**确认，再交付。
6. PWA 有 Service Worker 缓存：用户看不到新版本时，先让他刷新两次/清站点数据，再判断是不是代码没生效。
